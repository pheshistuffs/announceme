# AnnounceMe

Напоминания о сайтах в виде уведомлений Windows. Уведомление приходит «от сайта»:
в заголовке имя сайта и его иконка, а не браузер и не само приложение.

Например: от **chess.com**, с иконкой chess.com, текст «Обновились ежедневные задачи по шахматам».
Клик по уведомлению открывает сайт в браузере по умолчанию.

## Запуск

Скачайте `AnnounceMe.exe` и запустите. Ничего устанавливать не нужно (Windows 10 1809+ или Windows 11).
Приложение живёт в области уведомлений рядом с часами; закрытие окна его не выключает, выйти можно через меню значка.

- **Добавить…** — адрес сайта, имя отправителя, необязательный заголовок, текст, дни недели и время (можно несколько: `09:00, 18:30`).
- Иконка подтягивается с сайта сама; если не нашлась или не нравится, можно выбрать свою картинку.
- **Показать сейчас** / **Показать пример** — проверить, как выглядит уведомление.
- **Запускать вместе с Windows** — автозапуск в трее.
- **Показывать пропущенные** — если компьютер был выключен в нужное время, уведомление придёт после включения (если прошло не больше 12 часов).

Настройки и иконки хранятся в `%APPDATA%\AnnounceMe`.

## Как это устроено

Windows рисует в шапке уведомления имя и иконку того приложения, которое его отправило.
Поэтому для каждого сайта приложение регистрирует отдельного «отправителя»
(AppUserModelID в `HKCU\Software\Classes\AppUserModelId`) с именем сайта и его иконкой.
Из-за этого в «Параметры → Система → Уведомления» каждый сайт виден отдельной строкой,
и его можно выключить или настроить отдельно.

Ограничения:
- Если включён режим «Не беспокоить» / фокусировка, Windows спрячет уведомление в центр уведомлений.
- После изменения имени или иконки сайт регистрируется заново; старая строка может ещё какое-то время висеть в параметрах уведомлений Windows.
- Иконки в формате SVG не поддерживаются; тогда берётся favicon.ico или картинка из сервиса иконок Google/DuckDuckGo.

## Сборка из исходников

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0). Запустите `build.cmd`, готовый файл появится в `dist\AnnounceMe.exe`.
